1. Screen List

ScreenPurposePrimary OperationsSource
Home週間タイムラインと日次フォーカスを表示する。週移動、日選択、メモ編集、写真確認src/pages/home
Calendar月単位で活動日、祝日、予定を表示する。月移動、予定登録、予定編集、予定削除src/pages/calendar
Settings表示、フォント、通知、StellaRecord 連携を設定する。設定保存、DB パス指定、登録確認src/pages/settings
Snapshot Modal四半期・年間レビューを表示する。開封、既読化、閉じるsnapshot services
Photo Lightbox日次写真を拡大表示する。前後移動、閉じるsrc/pages/home
Debug開発用状態確認を行う。DEV ビルドのみ表示src/pages/debug

2. Navigation Structure

上部ナビゲーションで Home / Calendar / Settings を切り替える。Snapshot と Lightbox は現在画面の上にモーダル表示する。
App Shell
  ├─ Header navigation
  │   ├─ Home
  │   ├─ Calendar
  │   └─ Settings
  ├─ Main page
  │   ├─ Weekly timeline
  │   ├─ Day focus
  │   └─ Calendar month view
  └─ Global overlays
      ├─ Snapshot modal
      ├─ Reminder card
      └─ Photo lightbox

3. Common Layout Rules

AreaDefinition
Headerアプリ名、ページ切替、現在日付、設定入口を配置する。
Timeline lane7 日分の訪問ブロック、予定ピン、時間軸を同じ座標系で描画する。
Day focus選択日の訪問、同席ユーザー、写真、メモを縦方向に配置する。
ModalSnapshot、Lightbox、通知詳細など一時表示の情報を表示する。
Feedback保存、通知、DB 接続、StellaRecord 未検出はトーストまたは画面内状態で表示する。

4. Screen Layouts

Home: Weekly Timeline

週単位の訪問履歴と予定ピンを表示する。

┌ Header: week nav / today / settings ┐
├ Reminder cards                       ┤
├ Timeline controls: zoom / range      ┤
├──────────────────────────────────────┤
│ Mon │ Tue │ Wed │ Thu │ Fri │ Sat │ Sun
│ visit blocks + event pins             │
└ Selected day summary                  ┘

Home: Day Focus

選択日の訪問、同席ユーザー、写真、メモをまとめる。

┌ Day focus header: date / world count ┐
├ Visit blocks                         ┤
├ Co-present users / memokitto         ┤
├ Cork board photos                    ┤
├ Memo editor with markers             ┤
└ Save state / character count         ┘

Calendar

月間の活動日、祝日、予定を一覧する。

┌ Calendar header: month nav / add event ┐
├ Weekday row                             ┤
├ Month grid                              │
│ day: visits / holidays / events         │
└ Event editor panel                      ┘

Settings

表示・通知・DB 連携の設定を管理する。

┌ Settings header ┐
├ StellaRecord connection                ┤
├ Font and memo settings                  ┤
├ Transition / snapshot / reminder        ┤
└ Save status / error                     ┘
